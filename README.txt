HOW TO RUN ASSIGNMENTS
1. Install Visual Studio Code (optional) or use any text editor.
2. Open a .js file and run it in a browser console or with Node.js.
3. Assignment 2 uses prompt(), so run it in a browser (Chrome/Edge), not Node.js.
4. For browser console: open Chrome -> press F12 -> Console, then paste the file contents.
   Alternatively, create an HTML file that includes the JS with <script src="filename.js"></script>.
5. For the mini project, double-click Mini_Project_Inventory_Dashboard.html to open it in Chrome/Edge.
6. Test the project with different product names and prices; capture screenshots of the results.
